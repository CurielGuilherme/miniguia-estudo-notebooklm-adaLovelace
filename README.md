# miniguia-estudo-notebooklm-adaLovelace
### Desenvolvedor: Guilherme Curiel

## 📜 Descrição e contexto
Este projeto consiste em um miniguia de estudo utilizando o NotebookLM da Google sobre a vida e obra de Augusta Ada Byron King, Ada Lovelace. Desenvolvido como proposta no **Bootcamp de Cibersegurança - Riachuelo (2026)**.

## 🎯 Objetivos
*Aprender os principais conceitos da ferramenta NotebookLM;
*Desenvolver as habilidades de Engenharia de Prompt aprendidas no decorrer dos cursos ministrados;
*Treinar o modelo para ser um engrama de Ada Lovelace;
